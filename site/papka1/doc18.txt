# Аудит WillowinWorld — полный разбор

Анализ выполнен по исходникам в `/site`: статический HTML/CSS/JS без сборщика, ~3.1 MB ассетов, `styles.css` 267 KB, `scripts.js` 69 KB, `index.html` 62 KB, 58 `<img>` на главной. `node tools/security-check.mjs` — **passed**.

---

## 1. Краткий вердикт

| Направление | Оценка | Комментарий |
|-------------|--------|-------------|
| **Дизайн** | **7.5 / 10** | Сильная «storybook»-эстетика, живые карточки игр, но перегруз секциями и слабая визуальная иерархия CTA |
| **UX** | **6.5 / 10** | Понятно «кто вы» и «какие игры», но длинный скролл, дубли блоков, часть интерактива спрятана |
| **Frontend** | **6 / 10** | Хорошая семантика и a11y-паттерны, но монолитный CSS и отсутствие пайплайна |
| **Performance** | **5.5 / 10** | Умная адаптация canvas, но тяжёлый first load и 267 KB CSS на всех страницах |
| **Mobile** | **6 / 10** | Breakpoints есть, hero и анимации тяжёлые для слабых телефонов |
| **Branding** | **7 / 10** | Узнаваемый W/кот/портал, но позиционирование размыто между cozy и hardcore |

**Общий уровень:** сильный **indie studio site above average**, ещё не **AAA product landing 2026**. Ближе к «премиум-прототипу с production security», чем к финальному релизу для издателей.

## 2. Главные проблемы

1. **First load тяжёлый:** 267 KB CSS + 69 KB JS + preload двух крупных WebP (лого ~117 KB + Nature hero ~188 KB) на главной.
2. **Один `styles.css` на все страницы** — game pages тянут весь файл (~10.8k строк), хотя им нужна доля стилей.
3. **Главная перегружена:** Games → Roadmap → 8 фильтров → 4 тяжёлые карточки → Studio → Systems → About → Process → Devlog → FAQ → CTA (~9 «этажей»).
4. **Интерактив constellation/play mode в JS есть, UI-триггера нет** — `[data-play]` в HTML отсутствует, мини-игра со звёздами фактически недоступна.
5. **Кнопка «404» в production header** — ломает ощущение премиум-студии.
6. **58 изображений с `alt=""` на index** — SEO и screen readers теряют контекст игр.
7. **Candy/Ball карточки — десятки слоёв** (10 candy backgrounds, 16 clouds) → repaint/composite cost на mobile.
8. **Дублирование контента** `#studio`, `#systems`, `#about`, `#process` — одна мысль четырьмя блоками.
9. **Press kit отдаёт полноразмерные файлы** (например `ship.webp` 236 KB) без watermark/preview-tier.
10. **Нет build/minify** — gzip поможет, но архитектура не масштабируется под 5+ игр.

## 3. Что уже хорошо (сохранить и усилить)

- **Цветовая система** в `:root` / `[data-theme="light"]` — coherent night/day magic (`styles.css` строки 1–65).
- **Живые game covers:** Nature sketch→water→bloom, Candy merge stack, Paint cubes, Ball clouds — это реальный wow, не stock.
- **Performance-aware JS:** `prefers-reduced-motion`, `saveData`, FPS fallback `< 28`, pause при `document.hidden`, `is-animation-paused` на карточках (`scripts.js` 200–217, 1162–1180, 1664–1676).
- **Security-by-design:** strict CSP, no third-party, mailto вместо fake forms, `security-check.mjs`, `_headers`, nginx/apache configs, `SECURITY.md`.
- **Доступность базового уровня:** skip-link, `aria-*` на FAQ/modals, focus trap, `prefers-reduced-motion` в CSS.
- **SEO foundation:** JSON-LD VideoGame ×4, canonical, OG/Twitter, sitemap, press-kit.
- **Отдельные game pages** с тематическим hero — правильная модель портфолио.
- **404 как Easter egg** (`404.js` + touch controls) — в духе бренда.

## 4. Подробный аудит по разделам

### 4.1 Design / Art Direction

**Сильные стороны**
- Палитра: cyan `#71e7ff`, violet, rose, gold, grass — «волшебный storybook», не generic dark SaaS.
- Hero panel с Nature Seed loop (sketch → water → bloom) — сразу показывает **фирменную механику**, не абстрактный арт.
- Карточки игр — мини-сцены, не плоские thumbnails.
- Twin-W symbol block (`#about`) — зачаток сильной айдентики.

**Слабые места**
- **Типографика:** `h1` до `clamp(3.85rem … 5.05rem)` на hero — на 360px экране заголовок доминирует над preview; brand name + длинный tagline в два блока визуально «давят».
- **Кнопки hero:** 3 CTA одного веса (Beta / Explore / Publishers) — нет одного доминирующего действия.
- **Фильтры игр (8 штук)** визуально спорят с roadmap pills — два «контрольных» ряда подряд.
- **Header:** ghost-кнопка «404» рядом с Contact — anti-premium.
- **Footer** функционален, но без social proof (нет логотипов платформ, awards, «featured in»).
- **Light theme** иногда «детский пастель» vs **dark** «ночная магия» — переключение меняет характер бренда сильнее, чем у топ-студий (нужен единый emotional core в обеих темах).

**Как усилить**
- Сделать **один visual anchor** above the fold: только Nature Seed + «July 2026 beta» + один CTA.
- Упростить фильтры до 3–4 (All / Puzzle / Arcade / In dev).
- Добавить **1 full-bleed cinematic strip** между hero и games (15–20s loop video/WebP sequence) — без autoplay sound.
- Press-quality **wordmark SVG** вместо растра 1024×1024 в header.

### 4.2 UX

**Что работает**
- За 5 секунд ясно: mobile indie studio, 4 игры, Nature Seed — flagship.
- Навигация: Games, Studio, Devlog, Press Kit, Contact — логична.
- Contact через modal → mailto — честно, без «мёртвой формы».

**Проблемы**
| Проблема | Деталь |
|----------|--------|
| Длина страницы | ~880 строк HTML, много повторяющихся paragraph patterns |
| Redundant IA | `#studio`, `#systems`, `#about`, `#process` — nav ведёт только на `#studio` |
| Скрытый интерактив | Constellation `startPlayMode()` без `[data-play]` в DOM |
| Magic controls | JS ищет `#pauseMagic`, `#disableMagic` — в index их нет; FAQ обещает control, UI нет |
| Game discovery | Фильтры полезны, но roadmap + progress bars + tags + feature-callout = cognitive load |
| Devlog | Homepage teaser OK, но нет RSS/даты сортировки на hub |
| 404 в menu | Путает новых пользователей |

**Предлагаемая структура**

```
1. Hero — WillowinWorld + one-liner + Nature Seed beta CTA + living preview
2. Featured game — Nature Seed (80% width story)
3. Other worlds — 3 cards (compact)
4. Magic moment — constellation / portal (ONE interactive block, с явной CTA «Awaken stars»)
5. Studio — philosophy + team tone (merge studio/systems/about)
6. Devlog feed — 4 cards + «all updates»
7. For partners — publishers / press (compact)
8. Contact + footer
```

Убрать с главной или свернуть: Process timeline, FAQ (→ отдельная страница или footer accordion), Systems grid (→ внутрь Studio).

### 4.3 Frontend / Code Quality

**Плюсы**
- Семантика: `<main>`, `<article>`, `<nav aria-label>`, modals с `role="dialog"`.
- Нет inline handlers (security-check это enforce'ит).
- DOM из JS через `textContent`, не `innerHTML` (scripts.js policy).
- Game pages: только `game-theme.js` (8.5 KB) — правильное разделение.

**Минусы**
- **`styles.css` 10 837 строк / 267 KB** — god file; game-specific (nature, candy, ball, paint, press-kit, 404) всё вместе.
- **`index.html` 62 KB** — дублирование разметки Nature stage в hero + 4 карточках.
- **Dead code paths:** `themeState`, `magicState`, `pauseMagic`, `disableMagic`, `magic-console` в CSS — UI удалён, логика осталась.
- **Inline style mutation** на карточках (`--shine-x`) — ок, но усложняет CSP если когда-то понадобятся inline styles.
- **Нет модульности:** добавление 5-й игры = правки в 5+ местах (index, styles, scripts profiles, sitemap, JSON-LD).
- **Game page Nature:** один и тот же `Galvnie_3_*` блок повторяется 3 раза в `nature-seed.html` (строки 44–60, 77–92, …) — лишние HTTP-запросы при первом визите.

**Конкретные рекомендации**
1. Split CSS: `core.css` + `home.css` + `game-nature.css` … или `@layer` + critical CSS inline для hero.
2. Вынести game card covers в `<template>` или генерировать из JSON (один source of truth).
3. Вернуть **Magic panel** в footer или settings drawer: Pause / Low motion / Off (элементы уже в JS).
4. Добавить `[data-play]` на hero: «Connect the constellation».
5. Build step: `esbuild`/`lightningcss` minify — даже без React.

### 4.4 Performance

**Бюджет (факт)**

| Ресурс | Размер |
|--------|--------|
| styles.css | 267 KB |
| scripts.js | 69 KB |
| index.html | 62 KB |
| assets/ | ~3.1 MB |
| Крупнейшие WebP | `ship.webp` 236 KB, `Galvnie_3_1` 188 KB, logos 117–137 KB |

**Что может лагать и почему**

| Источник | Почему | Где |
|----------|--------|-----|
| Full-screen canvas rAF | Каждый кадр: фон, звёзды, частицы, кот, trails, bursts | `#magicCanvas` |
| Много CSS animations | Candy 10 layers, Ball 16 clouds, Nature water SVG | `.game-card` |
| Paint/composite | `backdrop-filter`, `mix-blend-mode`, shadows на больших блоках | hero, cards |
| Decode jank | 58 images на index, preload 2 heavy above fold | index.html:30–31 |
| Main thread | `scripts.js` 1870 строк sync init на load | конец scripts.js |

**Уже сделано правильно**
- Cap DPR 1.15–1.65, frame skip 31 FPS на mobile/low motion.
- Background cache canvas (`drawCachedBackground`).
- Lazy loading на card images.
- Pause animations off-screen (`is-animation-paused`).

**Обязательно до релиза**
1. Убрать preload `Galvnie_3_1` с главной или заменить на **LQIP ~20 KB**.
2. Responsive images: `srcset` для hero/logo (не грузить 1024×1024 в 38px brand mark).
3. Minify + Brotli: CSS/JS/HTML.
4. На mobile **отключать canvas по умолчанию** (static poster + toggle «Enable magic»).
5. Candy card: 10 backgrounds → **1 sprite sheet** или CSS gradient + 2 keyframes.
6. Проверить Lighthouse mobile на реальном хостинге (CLS от canvas resize, LCP от hero image).

**CLS риски:** canvas resize на `orientationchange`; modals без reserved space; animated card heights.

**LCP кандидат:** `Galvnie_3_1-site.webp` или logo — оптимизировать до <100 KB display size.

### 4.5 Motion / Interactive

**Что работает**
- Canvas: кот-маскот, луна/солнце, долина, клик-bursts — brand-aligned.
- Card hover shine (desktop only) — premium touch.
- Secret glints + letter hunt — хороший easter egg слой.
- 404 mini-game — отдельный интерактивный момент.

**Что мешает**
- Canvas **всегда активен** на главной — конкурирует с CSS-анимациями карточек.
- Constellation game **недоступна** без скрытого play mode.
- Нет **связи интерактива с конкретной игрой** на главной (portal/spell per game — только в CSS классах карточек).

**Идеи (с оценкой perf)**

| Идея | Perf | Приоритет |
|------|------|-----------|
| Магический курсор (CSS only, `mix-blend-mode`) | Безопасно | Средний |
| «Awaken constellation» CTA → play mode | Безопасно | Высокий |
| Particles только в hero viewport | Безопасно | Высокий |
| Per-game portal hover (seed/candy/paint/ball palette) | Средне | Высокий |
| Mini-game на 404 (уже есть) | Средне | Сохранить |
| Full-screen WebGL / Three.js | Опасно | Нет |
| Continuous parallax на scroll | Опасно на mobile | Низкий |
| Video backgrounds autoplay | Тяжело | Только desktop + reduced motion off |

### 4.6 Branding

**Запоминается ли WillowinWorld?** — Да, имя в hero крупно, twin-W, magic cat в canvas.

**Слабости positioning**
- Слоган размыт: «magical mobile games that feel alive» — подходит и Nature, и Candy, и Ball, но **не отстраивает** от других cozy studios.
- Четыре игры в разных жанрах без **единой «studio DNA» строки** (например: *«Tactile physics worlds you can feel in one touch»*).
- Tone of voice хороший (warm, confident), но много marketing-repeat: «tactile», «cozy», «premium» без конкретики.

**Рекомендации**
- **Слоган:** «We build mobile worlds you can feel in one touch.» + sub: draw, merge, blast, descend.
- **Visual hook:** always show **twin-W + cat + water line** — фирменная тройка.
- **Logo:** vector W-portal; WebP только для OG.
- **Trust row:** «Mobile-first · Physics-led · Beta 2026» + store icons (even «Coming soon»).
- Press kit: **one-page PDF factsheet** link alongside HTML.

**Для Steam / publishers / investors:** press-kit + game pages достаточны; главной не хватает **metrics slide** (team size, timeline, monetization hint, contact SLA).

### 4.7 Security (defensive)

**Реальный профиль: очень сильный для static site.**

| Контроль | Статус |
|----------|--------|
| Strict CSP (no inline JS except hashed JSON-LD) | ✅ |
| No fetch/XHR/WebSocket in client | ✅ |
| Contact → mailto, `form-action 'none'` | ✅ |
| Headers: HSTS, XFO DENY, COOP, CORP | ✅ (при деплое `_headers`/nginx) |
| security.txt | ✅ |
| security-check CI script | ✅ |
| No secrets in JS | ✅ |
| Theme localStorage validated | ✅ |

**Риски (низкие–средние)**

| Риск | Критичность | Mitigation |
|------|-------------|------------|
| CSP только meta на HTML без server headers | Средняя | Обязательно deploy `_headers` |
| mailto form — нет server-side spam filter | Низкая | OK для static; при Formspree — rate limit |
| Secret rewards «skin» в UI — social engineering если добавят real codes | Средняя при будущем backend | Server-side redemption only |
| Asset hotlinking | Низкая | CDN Referer policy |
| No Subresource Integrity (нет внешних ресурсов) | N/A | — |
| `Cache-Control: no-cache` на HTML | OK security, hurts perf | Separate immutable assets (уже есть `/assets/*`) |

**Перед публикацией**
1. Verify live headers (securityheaders.com).
2. HTTPS only + redirect.
3. MFA на GitHub/hosting/DNS.
4. Не класть в `site/` приватные builds, PSD, API keys.
5. При добавлении analytics — пересобрать CSP hash/allowlist.

**XSS:** практически закрыт (no innerHTML, strict CSP). **Clickjacking:** `frame-ancestors 'none'`. **CSRF:** нет state-changing endpoints.

### 4.8 Защита от копирования ассетов

| Мера | Эффект |
|------|--------|
| WebP preview-only в public | **Реально полезно** |
| Watermark на press downloads | **Реально полезно** |
| Не выкладывать PSD/4K/源 files | **Реально полезно** |
| `Referer` hotlink protection на CDN | **Частично** |
| robots Disallow `/private/` | **Частично** (security through obscurity) |
| JS minify/obfuscation | **Частично** |
| Disable right-click / drag | **Иллюзия** |
| «Запретить скачивание» HTML | **Иллюзия** |

Сейчас press-kit даёт прямые ссылки на полные WebP (`ship.webp` 236 KB) — для публики OK, для защиты арта — добавить **отдельный `-press.webp` с watermark** и lower resolution.

### 4.9 Mobile-first

**Плюсы**
- Breakpoints 1120 / 920 / 640 px.
- `100svh` hero, touch-friendly nav toggle.
- `hero-worlds` → 2 columns на 640px.
- Game animation pause off-screen.
- 404: touch buttons.

**Минусы**
- Hero **min-height 100svh** + panel 420–480px → много скролла до Games.
- **3 hero buttons** в столбик — длинный thumb path.
- Canvas magic на touch — bursts on `touchend` могут мешать scroll (click handler на window).
- `hero-note` скрывается на game pages при 640px — теряется beta date.
- 16 cloud images в Ball card — риск dropped frames на Mali-G57 tier.

**Конкретные mobile fixes**
1. Hero: 1 primary CTA, остальное в «More».
2. `touch-action: manipulation` на interactive cards.
3. Default `body.low-motion` на `(max-width: 640px)` OR user never sees canvas until opt-in.
4. Увеличить tap targets фильтров до min 44×44px (проверить `.filter-btn` padding).
5. Sticky bottom bar: Games | Beta | Contact.

## 8. Финальная концепция идеального сайта WillowinWorld

### Структура
```
/                 → Cinematic hero + 4 worlds + magic ritual + studio + devlog + partners
/games/[slug]     → Immersive single-game story (уже почти есть)
/press-kit        → Facts + gated downloads
/404              → Lost stars game (оставить)
```

### Визуальный стиль
- **«Enchanted storybook mobile studio»** — watercolor nature + candy gloss + paint splatter + divine verticality, но **единая типографика и сетка**.
- Day/night = освещение одного мира, не два разных бренда.
- Wordmark SVG twin-W + cat silhouette как favicon system.

### Интерактив
- **Главный ритуал:** constellation на canvas (явный CTA).
- **Вторичный:** secret letters + 404 game.
- **Третичный:** per-card CSS scenes (без 10+ images где можно).

### Анимации
- Hero: 1 loop.
- Scroll: reveal (уже есть).
- Rest: pause off-screen (уже есть).
- Mobile default: static beauty + opt-in magic.

### Атмосфера
- Calm confidence, не «кричащий indie».
- Первые 3 секунды: *touchable physics worlds*.
- Для издателя: clarity > spectacle.

### Техническая база
- Static site + `security-check` CI.
- Build: minify, split CSS, image pipeline (sharp/cli → webp q=80).
- Optional: Eleventy/astro для DRY game data из `games.json`.

### Безопасность
- Текущая модель сохранить.
- Любой backend (forms, beta keys) — **отдельный API subdomain**, не в static repo.
- Rewards/secrets — server redemption only.

**Итог:** у WillowinWorld уже есть **душа, арт и security-зрелость** уровня студии, которая серьёзно относится к релизу. # Полный аудит WillowinWorld (продолжение)

Аудит по репозиторию `site/`: статический сайт без сборки, ~10 836 строк CSS, ~1 870 строк JS на главной, 7 HTML-страниц, ~3.1 MB ассетов.

## 2. Главные проблемы

1. **Монолит `styles.css` (~267 KB / ~10.8k строк)** — грузится на всех страницах, включая game pages с `game-theme.js` (~8.5 KB).
2. **Главная перегружена контентом и картинками** — 58 `<img>`, Candy (10 фонов), Ball (16 облаков) в одной сетке.
3. **LCP под ударом** — `preload` логотипа (~117 KB) + `Galvnie_3_1-site.webp` (~188 KB) до первого осмысленного контента.
4. **Мёртвый интерактив в JS** — `gameModal` и режим созвездия (`data-play`, `data-game`) **нет в HTML**; логика есть, входа для пользователя нет.
5. **Дублирование секций** — `#studio`, `#systems`, `#about`, `#process` повторяют одну мысль четырьмя блоками.
6. **Кнопка «404» в production-header** — выглядит как внутренняя ссылка для теста, не для издателя/игрока.
7. **Все декоративные изображения с `alt=""`** — SEO и screen reader теряют контекст игр.
8. **Canvas magic loop на всю страницу** — даже с throttling на mobile это постоянный GPU/CPU cost.
9. **Game pages дублируют тяжёлые сцены** (Nature: одна и та же сцена до 3 раз в DOM).
10. **Press kit отдаёт крупные preview напрямую** (`ship.webp` ~236 KB) без watermark / tiered downloads.

## 3. Что уже хорошо (сохранить и усилить)

- **Арт-направление:** палитра (`--cyan`, `--brand-w`, `--rose`, day/night), «иллюстрированный» фон `body::before/::after`, карточки с мини-сценами игр.
- **Hero Nature Seed** — sketch → water → bloom в `.hero-panel` — сильнейший brand moment на сайте.
- **Roadmap + progress pills** — честно показывает стадии (Beta 99%, Internal beta и т.д.) → доверие издателей.
- **Фильтры игр** с `aria-pressed` и `data-tags` — продуманно.
- **Performance-инженерия в JS:** `prefers-reduced-motion`, `saveData`, FPS fallback → `low-motion`, pause при `visibilitychange`, `IntersectionObserver` для паузы анимаций карточек.
- **Security baseline:** meta CSP + `_headers` + `tools/security-check.mjs` + `SECURITY.md` — редкость для static indie.
- **Контакт через mailto** — нет утечки API-ключей и attack surface формы.
- **Отдельные game pages + press-kit + JSON-LD VideoGame** — готово для SEO и партнёров.
- **404 как мини-игра** — отдельный wow-слой (если убрать из header).

## 4. Подробный аудит по разделам

### 4.1 Design / Art Direction

**Сильные стороны**
- Единый «магический mobile cozy» язык: glass surfaces, glow, runes, portal badge.
- Карточки игр — по сути **мини-трейлеры в CSS**: Nature restoration, Candy merge stack, Paint cubes, Ball descent.
- Типографика: крупные display-заголовки (`hero h1` до ~5rem), balance на `.section-title`.
- Бренд **WillowinWorld** в шапке с подсветкой букв **W** — запоминается.

**Слабые места**
- **Визуальный шум на scroll:** фон + canvas + карточки с 10–16 слоями → конкурируют за внимание.
- **Hero h1 дублируется:** «WillowinWorld» в заголовке и в `.hero-brand-title` — избыточно.
- **Три CTA в hero** + 4 mini-links — на 390px экране плотно; иерархия «главного действия» размыта (Beta vs Explore vs Publishers).
- **Иконки principles/systems** — generic SVG, не игровые; ниже уровня карточек игр.
- **Стили `.magic-console` в CSS есть, в HTML нет** — признак недоведённого art/UI слоя.

**Как сделать дороже**
- Один **signature motion** на весь сайт (например, «линия воды» из Nature Seed как переход между секциями).
- Сжать палитру до 1 hero-accent на экран (сейчас cyan + gold + rose + green одновременно).
- Заменить generic icon grid на **1 кадр из каждой игры** в блоке философии.

### 4.2 UX

**Понятно ли, чем занимается студия?**  
Да, с первого экрана: mobile-first, 4 игры, Nature Seed как flagship.

**Предлагаемая структура (упрощённая)**

| Блок | Содержание |
|------|------------|
| **Hero** | 1 слоган + 1 primary CTA (Beta) + 1 secondary (#games) + living Nature panel |
| **Games** | Roadmap strip + 4 карточки (без 8 фильтров на первом экране — вынести в «All tags») |
| **Magic / Interactive** | Созвездие, секретные буквы, toggle magic — **с явной CTA «Awaken the sky»** |
| **Studio** | 1 блок: философия + twin-W + 3 факта (mobile / tactile / 2D) |
| **Devlog** | 4 карточки (как сейчас) |
| **Trust** | Press / Publishers / FAQ (сжатый) |
| **Contact** | CTA + mailto |
| **Footer** | Без dev-link «404» |

**Критичные UX-баги в коде**
- `initGameDetails()` ищет `[data-game]` — **в `index.html` таких элементов нет** → модалка `#gameModal` не открывается с карточек (только «Game Page»).
- `startPlayMode()` вешается на `[data-play]` — **тоже нет в HTML** → мини-игра созвездия недоступна.
- Секреты (`secret-glint`) работают, но **без onboarding** пользователь не поймёт механику.

**Перегруз:** ~9 крупных секций до footer — для игрока ок, для издателя длинно; нужен **«Publisher jump»** (якорь / sticky bar).

### 4.4 Performance

**Ориентиры по репозиторию**

| Ресурс | Размер |
|--------|--------|
| `index.html` + `styles.css` + `scripts.js` | **~398 KB** (без gzip) |
| `styles.css` | **267 KB** |
| `scripts.js` | **69 KB** |
| `assets/` | **~3.1 MB** |
| Крупнейшие файлы | `ship.webp` 236 KB, `Galvnie_3_1` 188 KB, logos ~117–137 KB |

**Что будет лагать и почему**

| Источник | Почему | Где |
|----------|--------|-----|
| Full-screen canvas rAF | Рисует небо, холмы, замок, кота, частицы каждый кадр | `magicCanvas` + `render()` |
| 58 изображений на главной | Декодирование, память | `#gamesGrid` |
| Candy 10× `back_glavnie_*.webp` | Даже с `lazy` — тяжёлый DOM | `.candy-bg-stack` |
| Ball 16 clouds | 16 отдельных img + CSS animation | `.ball-cloud-field` |
| `backdrop-filter: blur` на `.eyebrow`, cards | Дорого на mobile GPU | по всему CSS |
| `will-change: transform` на многих слоях | Лишние compositor layers | game cover CSS |
| Preload 2 heavy images | Конкурируют с LCP text | `<head>` index |

**Уже сделано правильно**
- Throttle 31 FPS на mobile / low-motion.
- Background cache canvas.
- `is-animation-paused` вне viewport.
- Budget 512 KB на asset в `security-check.mjs`.

**Перед релизом обязательно**
1. Brotli/Gzip на CDN + `Cache-Control` для assets (в `_headers` уже есть immutable для `/assets/*`).
2. Сжать hero preload до **одного** LCP-изображения (скорее painted level ~80–120 KB WebP).
3. Responsive images: `srcset` для icons 640→256 display size.
4. Разделить CSS; game pages не должны тянуть paint/ball/candy анимации с главной.
5. Lighthouse mobile: цель LCP < 2.5s, INP < 200ms (canvas + scroll listeners влияют на INP).

### 4.7 Security (defensive)

**Реальные риски**

| Риск | Критичность | Статус |
|------|-------------|--------|
| XSS через innerHTML | — | Запрещено в security-check |
| XSS через форму | Низкая | mailto only, нет server |
| Clickjacking | Низкая | `frame-ancestors 'none'`, XFO DENY |
| MIME sniffing | Низкая | `nosniff` |
| Supply chain (CDN scripts) | — | Нет внешних скриптов |
| CSP слишком строгий для будущего | Инфо | `connect-src 'none'` — сломает analytics/forms |
| Утечка ассетов | Средняя | Прямые URL на webp в press-kit |
| Hosting misconfig | Средняя | Нужна проверка live headers |
| localStorage theme | Низкая | Валидация `dark`/`light` есть |

**Перед публикацией**
1. HTTPS + применить `deploy/nginx-security.conf` или `_headers`.
2. `node tools/security-check.mjs` в CI.
3. `security.txt` уже в `.well-known/` — ок.
4. При добавлении формы — server-side only, не Formspree key в JS.
5. Subresource Integrity если появятся внешние скрипты.

**Secret rewards в JS:** текст про «skin reward» — **не внедрять реальные коды** в frontend (у вас в SECURITY.md это уже указано верно).

### 4.8 Защита от копирования

| Мера | Эффект |
|------|--------|
| Preview WebP ≤512 KB, не PSD/Unity в `site/` | **Реально полезно** |
| Watermark на press assets | **Реально полезно** |
| Hotlink protection (CDN) | **Частично** |
| `Referrer-Policy` | **Частично** |
| robots Disallow `/private/` | **Частично** (если папки нет — символически) |
| JS obfuscation | **Иллюзия** |
| `user-select: none` | **Иллюзия** (легко обойти) |
| Disable right-click | **Иллюзия** + вред UX |
| «Запрет скачивания» HTML | **Невозможно** |

**Практика:** в press-kit — zip с watermark + low-res; full-res по email; `ship.webp` не отдавать как открытый `<a href>` без tier.

### 4.9 Mobile-first

**Плюсы:** `100svh` hero, breakpoints 1120/920/640, touch targets на nav, `hero-worlds` → 2 колонки, stats 3-col.

**Минусы**
- Canvas на весь viewport — battery drain.
- `hero-worlds` 2×2 с мелким текстом 0.75rem — на 320px тесно.
- 3 кнопки hero в столбец — длинный first screen.
- `.nature-hero-note` скрыт на mobile (`display: none`) — теряется контекст Beta July 2026.
- Game hero showcases `min-height: 410–520px` — много скролла до текста.

**Конкретные улучшения**
1. Sticky bottom bar: Games | Beta | Contact.
2. Отключить canvas на `(max-width: 640px)` или `(pointer: coarse)` по умолчанию.
3. Hero: один CTA, остальное в «More».
4. Увеличить `hero-worlds span` до 0.8rem min.
5. Показывать `nature-hero-note` как 1 строку под CTA.

## 1. Что ещё удалось найти

### Дизайн
- **28× `backdrop-filter`** + **fixed header** с `blur(18px)` — при скролле под шапкой постоянно пересчитывается «стекло» (типичный источник micro-freeze на iPhone; см. [обсуждение Phanpy #212](https://github.com/cheeaun/phanpy/issues/212), [ColorFYI — backdrop-filter](https://colorfyi.com/blog/web-color-performance/)).
- **70× `filter:` / 146× `clip-path` в анимациях** (например `natureBackdropRepaint` анимирует `clip-path` + `filter`) — дороже, чем анимация только `transform`/`opacity` ([web.dev — filter effects](https://web.dev/articles/understanding-css)).
- **172 z-index** в одном файле — риск «невидимых» перекрытий при добавлении модалок/тостов/секретов.
- **`.brand-w` с `background-clip: text` + двойной `drop-shadow`** — красиво, но на слабых GPU увеличивает paint cost в шапке на каждом кадре скролла.

### UX
- **Мёртвые UX-ветки в JS без HTML:** нет `[data-play]` (созвездие), нет `[data-game]` (quick-view modal) — пользователь не может получить задуманный опыт, хотя код и модалки есть.
- **Easter eggs (`secret-glint`):** ~10 невидимых кнопок (`opacity: 0`) с `aria-label="Hidden portal symbol"` — для screen reader это «пустые порталы» без контекста; для sighted users — ноль discoverability.
- **Фильтр `tags.includes(filter)`** — хрупкая логика (см. раздел причин); на press-kit есть `aria-live` для фильтра, на главной — **нет** `data-filter-status`.
- **Навигация не покрывает половину страницы:** в меню есть `#studio`, но нет `#about`, `#systems`, `#process`, `#faq` — при скролле «потерянность» и неверный `aria-current`.
- **Кнопка «404» в production-header** — сигнал «сайт ещё в dev», режет доверие издателя.
- **mailto как единственный «submit»** — на iOS без настроенной почты CTA «отправить» может ничего не сделать (типичный UX-кейс, не баг кода, но риск конверсии).

### Frontend
- **Монолит `styles.css` (~10 836 строк / ~267 KB)** грузится на **все** страницы, включая game pages, которым нужна ~5–15% стилей.
- **Дублирование разметки Nature** на `games/nature-seed.html`: одни и те же `Galvnie_3_0/3_1` до **3 раз** в DOM → лишний decode памяти.
- **CSS `url("assets/Nature Seeds/...")` с пробелами** в путях (`repeat-y`, `max(100vw, 1440px)`) — на game-страницах фон может тянуть **сотни KB при каждом вертикальном скролле** через repaint большого background.
- **`game-theme.js` — бесконечный `requestAnimationFrame`** после первого `pointermove`: цикл **не останавливается**, пока не сработает `document mouseleave` (строки 137–167). На game pages курсор-маскот крутит rAF постоянно после первого движения мыши.
- **Apache vs Cloudflare `_headers`:** в `.htaccess` CSS/JS кэшируются **1 час**, в `_headers` для HTML — `no-cache`, для `/assets/` — 1 год. При смешанном деплое легко получить неожиданный cache mix.
- **Внутренние ссылки `index.html#games`**, canonical — `https://willowinworld.com/` → риск **дубля URL** `/` vs `/index.html` для SEO (зависит от хостинга).

### Performance
- **Прогноз critical path главной:** HTML+CSS+JS ≈ **398 KB** до gzip + 2 preload (logo ~117 KB + level ~188 KB) → LCP-кандидат почти наверняка **картинка**, не текст.
- **58 `<img>` на index** — даже с `lazy` ниже fold, при фильтрации/скролле к `#games` всплеск decode.
- **Candy: 10 фонов в DOM; Ball: 16 cloud img** — при входе в viewport снимается `is-animation-paused`, но **узлы остаются**.
- **Canvas `shadowBlur` в цикле отрисовки** (bursts, trails, stars) — известный GPU cost; на mid Android даст просадку после нескольких тапов.
- **`prefers-reduced-motion` в CSS** обнуляет анимации, но **canvas loop на главной всё равно стартует** (если не сработал ранний `lowMotion` по saveData) — частичный, не полный degrade.

### Mobile
- **Fixed header + `100svh` hero** — на iOS Safari адресная строка меняет viewport; `svh` лучше `vh`, но **safe-area-inset** для notch/ home indicator **не найден** в CSS.
- **`.hero-worlds` → 2 колонки на 640px** с текстом 0.75rem — на **320px** подписи жанров почти нечитаемы без zoom.
- **Скрытие `*-hero-note` на mobile** (Nature/Candy/Paint/Ball) — теряется ключевой контекст «Beta July 2026» на game pages.
- **Touch: глобальные `click`/`touchend` на `window`** в `scripts.js` для magic bursts — возможны **случайные вспышки** при тапе по кнопкам (частично отфильтровано `closest("button, a, ...")`, но не все интерактивы).
- **Game cursor mascots** отключены на coarse pointer — правильно; **главный canvas — нет** такого же hard-off по умолчанию на touch.

### SEO
- **Sitemap без `404.html`** — правильно (`noindex` на 404).
- **Все ключевые game images с `alt=""`** — Google Image Search и accessibility теряют сигналы; текст есть в `aria-label` на `article`, но **не на `<img>`**.
- **JSON-LD VideoGame** без `url`, `image`, `datePublished` — богатые сниппеты ограничены.
- **Один `lang="en"`** при возможной СНГ-аудитории — нет `hreflang` (если планируется RU).
- **Пробелы в URL ассетов** (`Nature%20Seeds`) — не ломает SEO, но хуже для sharing/CDN rules.

### Accessibility
- **Мобильное меню без focus trap** — при `menu-open` Tab уходит на контент под меню (модалки делают trap, меню — нет).
- **`.main-nav a { outline: none }`** на hover/focus path — компенсируется на части элементов, но **hero-worlds** тоже `outline: none` при `:focus-visible` (есть только border/transform — нужно проверить контраст фокуса).
- **FAQ** — нет `aria-controls` / связи с панелью, только `aria-expanded` (работает, но слабее для SR).
- **Секретные кнопки** — фокусируемые, но невидимые до focus/hover → **ловушка для keyboard users** (10+ таб-стопов).
- **Модалки:** `hidden` + focus trap есть; **`inert` на фоне нет** — фон теоретически фокусируем в edge cases.

### Security
- **Сильная база:** CSP, nosniff, COOP/CORP, no external scripts, `textContent` вместо HTML, `security-check.mjs`.
- **CSP meta + HTTP header** — при двойной политике браузер применяет **пересечение (строже)** ([MDN / CSP multiple policies](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy)); `connect-src 'none'` заблокирует любой будущий analytics без обновления CSP.
- **`frame-ancestors` только в HTTP CSP** — meta его **не поддерживает** ([csplite / MDN](https://csplite.com/csp67/)); без nginx/_headers кликджекинг через iframe теоретически возможен.
- **`require-trusted-types-for 'script'`** — продвинуто; при расширении JS нужно соблюдать Trusted Types (сейчас ок при `textContent`).
- **mailto injection:** subject/body из формы — не XSS на сайте, но **CRLF/header injection в mail-клиент** теоретически возможен при `\n` в полях (низкий риск, зависит от клиента).
- **Нет Privacy Policy / cookie banner** — localStorage `willow-theme` юридически спорен для EU (скорее exempt, но лучше упомянуть в privacy).

### Защита ассетов
- **`press-kit.html` прямые ссылки на full `.webp`** (в т.ч. `ship.webp` ~236 KB) — легальный hotlink/download.
- **Два полных логотипа** (day/night ~117+137 KB) — удваивает «кражу» бренда.
- **`security-check` блокирует >512 KB** в `assets/` — хорошо; `ship.webp` в пределах, но всё ещё крупный оригинал для web.
- **Папки с пробелами** — не дыра, но усложняет WAF/CDN правила.

### 🔴 Сделать в первую очередь

1. **Проверить live security headers** (`securityheaders.com` / curl) — без nginx/`_headers` сайт **не** защищён от clickjacking так, как задумано.

7. **Redirect `/index.html` → `/`** на сервере — SEO hygiene.
8. **`node tools/security-check.mjs` в CI** перед каждым деплоем.

## 7. Честный вывод

### Самый надёжный фикс (пакет для релиза)
**Mobile perf triad:** отключить/сузить canvas на touch + убрать header backdrop-filter на mobile + один LCP preload + split или purge CSS для subpages. Это даёт измеримый выигрыш без смены визуальной концепции.

### Что лучше не использовать
- **Right-click block, obfuscation, «защита от скачивания»** — иллюзия, вред UX/SEO.
- **Formspree/API keys в frontend** при вашей CSP-философии — ломает модель безопасности.
- **Fullscreen canvas на всех устройствах** как default — противоречит mobile-first.
- **Оставить мёртвый gameModal/playMode** без UI — хуже, чем удалить (ощущение недоделки).

### Перед финальным решением проверить
- Реальный хостинг: применяются ли `_headers` / nginx / apache (не только meta CSP).
- Lighthouse на **прод-домене**, не `file://`.
- iOS Safari на реальном устройстве (backdrop + svh + mailto).
- Дубли URL `/` vs `/index.html`.
- Нужен ли вам **server form** для издателей (если да — планируйте CSP `connect-src` заранее).

### Неопределённость
- Точные LCP/INP без live run.
- Поведение конкретного CDN (Cloudflare vs nginx only).
- Влияние `require-trusted-types-for` на старые браузеры (мало данных, низкий риск).

### При росте сайта
- Монолит CSS станет **неподдерживаемым** (>15k строк).
- Ручное обновление CSP hash для JSON-LD при каждом изменении — точка отказа (у вас уже есть check — хорошо).
- Больше игр → больше дублирующихся card CSS blocks — нужен build/design tokens.

### Production-ready?
**Нет, в текущем виде для публичного релиза уровня «издатель + массовый mobile трафик»** — из‑за perf-бюджета (CSS + canvas + images), UX-долгов (мёртвый интерактив, 404 в header), a11y (menu, secrets), SEO (alt, duplicate URLs).  

**Да для закрытой beta / портфолио для знакомых партнёров**, если задеплоить security headers и принять mobile perf компромиссы.

### Подтверждено кодом vs нужны тесты
| Утверждение | Статус |
|-------------|--------|
| Мёртвые `data-play` / `data-game` | **Подтверждено** (grep) |

## 1. Что ещё удалось найти

### Дизайн
- **OG/Twitter превью:** везде квадратные иконки 1024×1024 / 520×520 при `summary_large_image` — в Discord/Telegram/LinkedIn обрежется, слабый **link preview** ([рекомендация ~1200×630](https://developers.facebook.com/docs/sharing/webmasters/images/)).
- **Press-kit nav:** якоря оформлены как `filter-btn` — визуально «фильтр», по смыслу «разделы» → когнитивный диссонанс.
- **Фильтр «Mobile»** на главной и press-kit: у всех 4 карточек есть тег `Mobile` → кнопка **бесполезна**, создаёт ощущение сломанного UI.

### UX
- **Тема по умолчанию в HTML — всегда `light`** на всех страницах (`<body data-theme="light">`), хотя JS потом читает `prefers-color-scheme` / `localStorage` → **вспышка светлой темы** у dark-пользователей до конца `scripts.js` / `game-theme.js`.
- **Случайный secret на каждый reload** (`secretRewards[Math.floor(Math.random()...)]`) — нельзя «дойти» до награды стабильно; для игрового сайта это скорее раздражитель, чем easter egg.
- **Press-kit ≈ клон блока `#games` с index** (те же карточки, те же тексты, те же `id="nature-card"` и т.д.) — при правках легко **рассинхронить** факты (July 2026, % beta).

### Frontend
- **Без JavaScript контент с `[data-reveal]` остаётся `opacity: 0`** — сайт выглядит «пустым» (нет `<noscript>` fallback).
- **Двойной вызов magic-tap на touch:** одновременно `window.addEventListener("click", handlePointerDown)` и `touchend` → **двойные burst-эффекты** ([классическая проблема touch+click](https://patrickhlauke.github.io/getting-touchy-presentation/); лучше один `pointerup` — [MDN Pointer events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events)).
- **`initActiveNavigation`:** IO вызывает `setActiveSection` для **каждой** пересекающейся секции подряд — «побеждает» последняя в batch, не верхняя → **мигающий/неверный active** в nav при скролле через `#about` / `#systems` / `#process` (их нет в меню).
- **178× `color-mix()`** без запасных значений — на Safari **&lt; 16.2** / старых Android WebView бордеры/фоны могут **не отрисоваться** (проверить на Can I use; fallback не везде).
- **Press-kit + index:** дублирование ~400 строк разметки игр — антипаттерн **copy-paste architecture** (любая студия через 6 месяцев ломает sync).

### Performance
- **404-страница:** `requestAnimationFrame(frame)` **всегда крутится**, даже в idle до Start — второй тяжёлый canvas-сайт.
- **404 sprite pipeline:** на каждый из 10 спрайтов — `getImageData` + flood-fill на main thread при load → **длинные задачи** (Long Tasks) при первом заходе на 404.
- **`[data-reveal]`:** десятки элементов с `opacity:0` + transition — при скролле IO добавляет классы → **layout+paint волна** на слабых CPU.
- **Дублирование обработчиков resize/move** на главной: глобальные listeners без teardown (норма для SPA, но при будущем partial navigation — утечки).

### Mobile
- **Нет `safe-area-inset`** для fixed header / bottom UI — на iPhone с notch кнопки header могут быть близко к краю (проверить в Safari).
- **Только 404.css имеет `touch-action: none`** на игровой области; главный canvas — `pointer-events: none`, но **scroll + magic listeners** на `touchmove` всё равно работают → лишняя работа при скролле пальцем.
- **Двойной tap burst** (см. выше) — ощущение «лага»/перегруза на touch.

### SEO
- **Дублирующийся текст** index ↔ press-kit («Four game worlds, one philosophy» + полные описания игр) — индексируется, но **размывает релевантность**; Google формально индексирует `display:none` ([Search Off The Record / Gary Illyes](https://www.seroundtable.com/google-not-visible-content-33630.html)), но **эксперименты** часто показывают преимущество видимого текста ([seoexamples.com — accordions](https://www.seoexamples.com/p/hidden-content-in-seo-unmasking-the)) — **нужен тест в GSC**.
- **FAQ ответы** свёрнуты через `grid-template-rows: 0fr` — в DOM есть, для SEO ок; для **featured snippet** хуже, чем открытый FAQ.
- **404 с `noindex`, но ссылка из header** — crawl budget тратится впустую (мелочь).
- **Внутренние ссылки `index.html#`** vs canonical `/` — риск двух URL (зависит от сервера).

### Accessibility
- **No-JS = невидимый контент** — провал progressive enhancement (критичнее, чем отсутствие alt).
- **10× `secret-glint` с `opacity:0`** — фокусируемые, SR видит «Hidden portal symbol» без контекста игры.
- **`aria-current="page"`** на якорях nav может прыгать из-за IO-бага.
- **FAQ:** нет `aria-controls` / `id` связки панели с кнопкой (только `aria-expanded`).

### Security
- **404: `?theme=light|dark` в URL** — безопасно (только класс), но стоит **валидировать** (уже есть) — ок.
- **Нет `.env`, source maps, ключей** в `site/` — хорошо.
- **CSP + JSON-LD hash:** при любом изменении structured data без обновления hash — **сайт ломается в браузерах с meta-CSP** (у вас есть `security-check` — это production-gate, не забыть в CI).
- **Secret modal обещает «skin reward»** — если позже подключите реальный код в JS, это станет **обманом + fraud vector**; сейчас безопасно, но опасно как product promise.

### Защита ассетов
- **404 sprites** в `assets/404/` (~188 KB, 10 файлов) — отдельный набор, не watermark; легко скачать по прямым URL.
- **Press-kit дублирует те же preview**, что и публичный сайт — удвоенная поверхность для скрейперов.

- **Обещания reward** в secret modal без backend — репутационный риск.
- **Два canvas-сайта** (index + 404) с вечным rAF как default — противоречит mobile-first narrative студии.

### Неопределённость
- Насколько `color-mix` ломает вид в вашей целевой аудитории — **нужен BrowserStack**, не код-ревью.
- Влияние duplicate press-kit на ранжирование — **нужен GSC 4–8 недель**.

### Production-ready?
По-прежнему: **для публичного масштабного релиза — нет** (perf + progressive enhancement + social + архитектурный долг).  
**Для закрытой beta / портфолио** — да, если закрыть 🔴 пункты выше.
