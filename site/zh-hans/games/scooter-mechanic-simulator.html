原型维修店模拟器

Scooter Mechanic Simulator

一个工位一个工位地修好滑板车。

一款第一人称维修店原型。顾客的电动滑板车从城市驶来。每辆车需要一到两项工作，在正确的工位完成后即可获得报酬。

Unity 项目包含一个有六个工位、可拾取与骑行滑板车、昼夜循环、存档和十种语言菜单的车间场景。目前尚无公开版本。

玩法循环

Scooter Mechanic Simulator 的玩法

  1. 步骤01滑板车抵达

    顾客的滑板车从城市的四个入口驶来，停在接待线旁。拿起一辆，搬进车库。

  2. 步骤02完成任务

    每辆滑板车都有一张含一到两项工作的维修卡。走到对应工位，完成其中的简短实操任务。

  3. 步骤03拿到报酬，把车搬出去

    最后一项完成的任务会结算报酬，滑板车即可搬出车库交还。HUD 会显示日期、你的金钱和声誉。

特点

工坊维修与检查机制

六个工位

清洗、平衡、安装、拆解、喷漆和试驾等工位，都会用鼠标和键盘把一次维修变成简短任务。

滑板车从城市驶来

顾客的滑板车从四个入口驶入接待线，队伍满了之后，多余的车会堆积在一旁。

搬运与骑行

使用 E 键可拾取并搬运滑板车，或骑行：Q 上车，A 和 D 转向，空格键蹬地，S 刹车。

维修卡

每辆滑板车都有一张一到两步的维修卡，工位只接受卡片要求的步骤。

昼夜循环与存档

一个工坊日持续十个真实分钟。进度保存到存档位，每两天自动存档一次。

十种语言菜单

主菜单与选项提供十种语言、难度设置，以及独立的音乐与音效音量。

Scooter Mechanic Simulator 常见问题

Scooter Mechanic Simulator 是哪种游戏？

一款第一人称维修店游戏。你把顾客的电动滑板车推进车库，在六个工位完成简短的实操任务，完成的维修任务会获得报酬。WillowinWorlds 与 Render Software Studio 合作开发本作。

Scooter Mechanic Simulator 现在发售了吗？支持哪些平台？

这是一个 PC 原型，使用键盘和鼠标操作。目前尚无公开版本、商店页面或发售日期。
