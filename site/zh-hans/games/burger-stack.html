原型街机堆叠游戏

Burger Stack

点击堆叠。完成订单。

将食材层投放到不断增高的汉堡上，保持对齐，并在搭建过程中完成配方。九种模式会改变堆叠的运动方式以及你要达成的目标。

九种模式、20 种食材和 166 种配方目录已在 Unity 项目中构建。目前尚无公开版本。

玩法循环

Burger Stack 的玩法

  1. 步骤01选择并投放

    图层会滑过堆叠，点击即可投放。在堆叠模式中，你可以从托盘中选择下一种食材。

  2. 步骤02干净落地

    悬出部分会被切掉，因此草率的投放会让堆叠变窄。接近中心的投放计为完美并累积连击。

  3. 步骤03搭出配方

    与配方匹配的食材层即可完成配方。在限时订单冲刺中，每完成一单会增加时间，放错食材则会减少时间。

特点

厨房模式与堆叠机制

九种模式

Stack Rush、Press Rush、Order Rush、Current Sort、Orbit Stack 3D、Stack 3D、Round 3D、Balance Tower 3D 和 Slice & Fit 3D，可从模式选择菜单中选取。

Expert X/Z 修饰规则

Stack Rush 带有可选的 Expert 修饰规则，可让图层沿两个轴移动。

20 种食材，166 种配方

肉饼、面包、番茄、培根、酱料、薯条等，配方目录包含两至七种食材的组合。

订单冲刺计时器

每完成一个订单，班次计时器就会增长；放错食材则会缩短。

插画厨房

水下与天空厨房背景随着堆叠增高而滚动，并配有对应的食材托盘和界面美术。

本地进度

保存在设备上的存档，会记录每日和每周挑战以及已解锁的食材。

方向

Burger Stack 版本状态与后续步骤

目前没有发售日期。这些是项目目标，并非承诺。

  • 发布前在低端 Android 手机上进行性能分析与质量测试。

问答

Burger Stack 常见问题

Burger Stack 是哪种游戏？

以汉堡为主题的点击堆叠街机游戏。你把食材层落在堆叠上，保持对齐并完成配方。共有九种模式，包括限时订单冲刺和 3D 变体。同样的单击理念也贯穿于 Sandwich Stack 和 Stack Tower.

Burger Stack 现在发售了吗？支持哪些平台？

还没有。Burger Stack 是原型，尚无公开版本，也没有发售日期。目标平台为 Android 和 iOS。

谁制作了 Burger Stack，我如何关注它？

Burger Stack 由独立手机游戏工作室 WillowinWorlds 制作（参见其 主要游戏）。请在本页链接的社交渠道关注 WillowinWorlds，或发邮件至 willowinworlds@gmail.com 以获取 Burger Stack 的更新信息。
