早期原型单击堆塔

Stack Tower

把握投放时机。搭建高塔。

起重机让每一层在塔顶上方摆动，你选择投放的时机。落点评级决定你的分数、稳定度和连击。

Unity 项目包含一个场景：起重机、楼层投放、落地评级、稳定度和 HUD，以及一座待堆叠的 20 层大楼。菜单、音频和进度尚未制作。

玩法循环

Stack Tower 的玩法

  1. 步骤01观察起重机

    起重机以钟摆方式摆动下一层，塔越高，摆动越快。

  2. 步骤02在正确的时机投放

    一次点击、鼠标单击或按下空格键即可释放楼层，它会落到塔上。

  3. 步骤03读懂落地

    每次落地都会评为完美、良好、冒险、失误或未命中，评级会影响你的稳定度、分数和连击。

特点

起重机时机与塔身平衡机制

摆动的起重机

每一层都由摆动的钟摆式起重机吊起。层数越高，速度、摆幅和投放高度都会增加，直到上限。

五级落地评级

完美、良好、冒险、失误和未命中取决于楼层偏离中心的距离以及与下层的重叠程度，每个评级的分数各不相同。

稳定度与倾斜

失误的落地会降低稳定度并让塔倾斜，而良好或完美的落地则会将其挽回。首座大楼开局稳定度为 92，有两条命。

六种楼层类型

普通、安全、精准、重型、技术和黄金楼层在重量、摆动速度、分数价值和稳定度影响上各不相同。

救援与奖励楼层

每隔六层会出现一个技术层，当稳定度偏低时会更早出现。连续五次完美落地会排入一个黄金层。

首座 20 层的大楼

住宅塔的目标是 20 层。当完成建筑、倒塌或生命耗尽时，本局结束。

问答

Stack Tower 常见问题

Stack Tower 是哪种游戏？

一款二维单击街机游戏。起重机让每一层在塔顶上方摆动，你松手投放，并根据落点评分。它与工作室的 Burger Stack 和 Sandwich Stack；这一款是侧视视角，带有起重机、地面类型和稳定度计。

Stack Tower 现在发售了吗？支持哪些平台？

还没有。这是为竖屏手机制作的早期原型。目前只有一个场景和一座大楼，尚无公开版本、商店页面或发售日期。

谁制作了 Stack Tower，我如何关注它？

Stack Tower 由独立手机游戏工作室 WillowinWorlds 制作（参见其 主要游戏）。请在本页链接的社交渠道关注 WillowinWorlds，或发邮件至 willowinworlds@gmail.com 以获取 Stack Tower 的更新信息。
