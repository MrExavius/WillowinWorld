原型街機堆疊遊戲

Burger Stack

點擊堆疊。完成訂單。

將食材層放到不斷成長的漢堡上，保持對齊，並在堆疊時完成食譜。九種模式會改變堆疊的移動方式與你要追求的目標。

Unity 專案中已製作九種模式、20 種食材，以及 166 道食譜目錄。目前尚無公開版本。

玩法循環

Burger Stack 的玩法

  1. 步驟01選擇並放下

    一層會在堆疊上方滑動，點擊即可放下。在堆疊模式中，你可以從托盤選擇下一個食材。

  2. 步驟02乾淨落地

    超出的部分會被切除，因此失誤的放下會留下較窄的堆疊。接近中心的放下計為完美並累積連擊。

  3. 步驟03製作食譜

    符合食譜的層會完成該食譜。在 Order Rush 中，每完成一筆訂單會增加時間，選錯食材則會扣除時間。

特點

廚房模式與疊疊機制

九種模式

Stack Rush、Press Rush、Order Rush、Current Sort、Orbit Stack 3D、Stack 3D、Round 3D、Balance Tower 3D 與 Slice & Fit 3D，皆可從模式選單選擇。

Expert X/Z 修飾符

Stack Rush 有一個選用的 Expert 修飾符，會讓層沿兩個軸移動。

20 種食材，166 道食譜

肉餅、麵包、番茄、培根、醬料、薯條等，食譜目錄包含兩到七種食材的組合。

Order Rush 計時器

班次計時器會隨每完成一筆訂單增加，選錯食材則會減少。

插圖廚房

水下與天空廚房背景會隨堆疊增長而捲動，並搭配相符的食材托盤與 UI 美術。

本機進度

儲存在裝置上的個人資料，會追蹤每日與每週挑戰以及已解鎖的食材。

方向

Burger Stack 開發狀態與後續步驟

目前尚無發售日期。這些是專案目標，並非承諾。

  • 在任何版本發布前，對低階 Android 手機進行效能分析與 QA。
  • 在水下與天空廚房之外，還會有更多廚房主題與外觀解鎖（設計構想，尚未製作）。
  • 食譜收集與精通目標（設計構想，尚未製作）。
  • 雲端存檔之後推出；目前進度僅儲存在本機。

問與答

Burger Stack 常見問題

Burger Stack 是哪種遊戲？

以漢堡為主題的點擊疊疊街機遊戲。把食材層放到堆疊上，保持對齊並完成食譜。有九種模式，包括限時訂單挑戰與 3D 變體。同樣的單點操作也貫穿 Sandwich Stack 和 Stack Tower.

Burger Stack 目前是否已推出？支援哪些平台？

尚未推出。Burger Stack 是原型，沒有公開版本，也沒有發售日期。目標平台為 Android 與 iOS。

誰開發 Burger Stack？如何關注？

Burger Stack 由獨立手機遊戲工作室 WillowinWorlds 製作（請參閱其 主要遊戲）。請在本頁連結的社群頻道關注 WillowinWorlds，或寄信至 willowinworlds@gmail.com 想獲取 Burger Stack 的最新消息。
