早期原型單點堆塔

Stack Tower

掌握放下時機，建起高塔。

吊車在塔上擺動每一層，由你選擇放下的時機。落點評分會決定你的分數、穩定度與連擊。

Unity 專案有一個場景：吊車、樓層放下、落地評級、穩定度與 HUD，附一座 20 層的大樓可供堆疊。選單、音訊與進程尚未製作。

玩法循環

Stack Tower 的玩法

  1. 步驟01注意吊車

    吊車以擺錘方式擺動下一層，塔越高擺動越快。

  2. 步驟02在正確時機放下

    按下一次單擊、點擊或空白鍵即可放下樓層，樓層會落到塔上。

  3. 步驟03判讀落地

    每次落地會評為完美、良好、冒險、失誤或未命中，評分會影響你的穩定度、分數與連擊。

特點

吊車時機與塔身平衡機制

擺動吊車

擺錘吊車負責搬運每一層。隨著樓層升高，速度、擺動幅度與放下高度都會增加，直到上限。

五種落地評級

完美、良好、冒險、失誤與未命中，取決於樓層偏離中心的程度，以及與下方樓層重疊的程度，各評級的計分方式也不同。

穩定度與傾斜

失誤落地會消耗穩定度並讓塔傾斜，良好或完美落地則能挽回。首座大樓起始穩定度為 92，並有兩條命。

六種樓層類型

一般、安全、精準、重型、技術與黃金樓層，在重量、擺動速度、分數價值與穩定度效果上各不相同。

救援與獎勵樓層

每六層會出現一次技術樓層，穩定度偏低時會更早出現。連續五次完美落地會排入黃金樓層。

首座 20 層的大樓

住宅大樓目標為 20 層。完成建築、倒塌或生命用盡時，一局結束。

問與答

Stack Tower 常見問題

Stack Tower 是哪種遊戲？

一款 2D 單點操作的街機遊戲。吊車在塔上擺動每一層，你決定放下的時機，落點會被評分。它與工作室的 Burger Stack 和 Sandwich Stack；這款是側視角，包含吊車、地板類型與穩定度儀表。

Stack Tower 目前是否已推出？支援哪些平台？

尚未推出。這是為直向手機設計的早期原型，目前只有一個場景與一座大樓，也沒有公開版本、商店頁面或發售日期。

誰開發 Stack Tower？如何關注？

Stack Tower 由獨立手機遊戲工作室 WillowinWorlds 製作（請參閱其 主要遊戲）。請在本頁連結的社群頻道關注 WillowinWorlds，或寄信至 willowinworlds@gmail.com 想獲取 Stack Tower 的最新消息。
