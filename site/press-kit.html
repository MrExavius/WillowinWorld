Factsheet

A small studio for tactile, magical mobile games.

Readable mechanics, mascot-led identity and polished UI are the core of every WillowinWorld project.

Studio pitch

Cozy systems with strong visual hooks.

WillowinWorld builds mobile-first game worlds where physics, characters, effects and interface feedback work together from the first touch. The portfolio spans draw-to-solve water routing, candy merge physics, color destruction and vertical arcade descent.

Draw-to-Solve Physics Puzzle

Nature Seed

Public Beta Planned Main genre: Draw-to-Solve Physics Puzzle
July 2026Beta polish

Nature Seed is a meditative draw-to-solve physics puzzle about drawing magical lines, guiding water toward seeds and restoring a dying forest into a living watercolor world. It is now in beta polish, with the first public beta planned for July 2026.

Mobile edge: line drawing, water routing and nature restoration become one calming physics loop.

Casual Merge Puzzle

Candy Shop

Internal Beta Main genre: Casual Merge Puzzle
BetaOptimization

Candy Shop is a cozy physics-based candy merge puzzle about dropping sweets, merging matching candies and building bigger treats through soft, satisfying physics. The game is now in internal beta, with optimization, UI polish, balance and combo readability as the current focus.

Mobile edge: Suika-like drops grow into candy combos, special sweets, containers and long progression.

Physics Puzzle / Arcade Hybrid

Paint Blasters

Production Draft Main genre: Physics Puzzle / Arcade Hybrid
DraftCore mechanics

Paint Blasters is a color destruction physics puzzle where players build color-powered projectiles before every shot, aim at readable towers and trigger chain reactions. The current GDD-based prototype has its core mechanics implemented in draft form while final scope is refined.

Mobile edge: build a color shot before aiming, then turn destruction into tactical chain reactions.

Ball is God?!

Longterm Project Main genre: Hardcore Arcade
PlannedAfter current releases

Ball is God?! is a hardcore vertical descent arcade about guiding Espa down a divine tower, slipping through broken stone gaps and surviving a mythic world where one mistake can end the run. It remains a longterm narrative arcade project planned after the current releases.
