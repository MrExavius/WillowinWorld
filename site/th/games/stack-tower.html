Stack Tower

จับจังหวะการปล่อย สร้างหอคอย

เครนแกว่งแต่ละชั้นเหนือหอคอย และคุณเลือกจังหวะปล่อย เกรดการลงจอดกำหนดคะแนน ความมั่นคง และสตรีคของคุณ

โปรเจกต์ Unity มีหนึ่งฉาก: เครน การปล่อยชั้น เกรดการลงจอด ความมั่นคง และ HUD พร้อมอาคารเดียวสูง 20 ชั้นให้เรียงซ้อน เมนู เสียง และความคืบหน้ายังไม่ได้สร้าง

วิธีเล่น Stack Tower

  1. ขั้นตอนที่ 01ดูเครน

    เครนแกว่งชั้นถัดไปเหมือนลูกตุ้ม แกว่งเร็วขึ้นเมื่อหอคอยสูงขึ้น

  2. ขั้นตอนที่ 02ปล่อยในจังหวะที่ถูกต้อง

    แตะ คลิก หรือกดปุ่มสเปซครั้งเดียวเพื่อปล่อยชั้น แล้วชั้นจะตกลงบนหอคอย

  3. ขั้นตอนที่ 03อ่านการลงจอด

    การลงจอดแต่ละครั้งได้เกรด Perfect, Good, Risky, Bad หรือ Miss และเกรดนี้ส่งผลต่อความมั่นคง คะแนน และสตรีคของคุณ

คุณสมบัติ

กลไกจังหวะเครนและสมดุลหอคอย

เครนแกว่ง

เครนลูกตุ้มยกแต่ละชั้น ความเร็ว การแกว่ง และความสูงในการปล่อยเพิ่มขึ้นทุกชั้นจนถึงขีดจำกัด

เกรดการลงจอดห้าระดับ

Perfect, Good, Risky, Bad และ Miss ขึ้นอยู่กับว่าชั้นลงห่างจากจุดศูนย์กลางแค่ไหนและซ้อนทับชั้นด้านล่างมากเพียงใด และแต่ละเกรดให้คะแนนต่างกัน

ความมั่นคงและการเอียง

การลงจอดที่แย่จะลดความมั่นคงและทำให้หอคอยเอียง ส่วนการลงจอดที่ดีหรือสมบูรณ์แบบจะเรียกคืนได้ อาคารแรกเริ่มที่ความมั่นคง 92 และมีสองชีวิต

ประเภทชั้นหกแบบ

ชั้นปกติ ปลอดภัย แม่นยำ หนัก เทคนิค และทองคำ ต่างกันที่น้ำหนัก ความเร็วการแกว่ง คุณค่าคะแนน และผลต่อความมั่นคง

ชั้นช่วยเหลือและชั้นโบนัส

ชั้นเทคนิคจะปรากฏทุกชั้นที่หก หรือเร็วกว่านั้นเมื่อความมั่นคงเหลือน้อย การลงจอดแบบ Perfect ห้าครั้งติดกันจะเข้าคิวชั้นทองคำ

อาคารแรกสูง 20 ชั้น

หอพักอาศัยมีเป้าหมาย 20 ชั้น การวิ่งจบเมื่อสร้างเสร็จ อาคารถล่ม หรือชีวิตหมด

ทิศทาง

สถานะบิลด์และขั้นตอนถัดไปของ Stack Tower

ยังไม่มีวันเปิดตัว นี่คือเป้าหมายของโปรเจกต์ ไม่ใช่คำมั่นสัญญา

  • อาคารเพิ่มเติมหลังหอพักอาศัย: หอคอยสำนักงาน ตึกระฟ้า บ้านหรู และหอคอยสถิติ (เอกสารแนวคิด)
  • ด่านแคมเปญและโหมดบันทึกไม่สิ้นสุด ตัวเลือกไม่สิ้นสุดมีอยู่แล้วในข้อมูลอาคาร (เอกสารแนวคิด)
  • ความคืบหน้าข้ามย่าน พร้อมดาวสำหรับอาคารที่สร้างเสร็จ (เอกสารแนวคิด)
  • หน้าจอผลลัพธ์พร้อมเสียงและภาพตอบรับการลงจอด (เอกสารแนวคิด)
คำถามและคำตอบ

คำถามที่พบบ่อยเกี่ยวกับ Stack Tower

Stack Tower เป็นเกมประเภทใด

เกมอาร์เคด 2D แตะครั้งเดียว เครนแกว่งแต่ละชั้นเหนือหอคอย คุณปล่อยชั้นลงและมีการให้เกรดการลงจอด ใช้แนวคิดการเรียงซ้อนแบบแตะเพื่อวางร่วมกับของสตูดิโอ Burger Stack และ Sandwich Stack; เกมนี้เป็นมุมมองด้านข้างพร้อมเครน ประเภทพื้น และมิเตอร์ความมั่นคง.

Stack Tower เปิดตัวแล้วหรือยัง และรองรับแพลตฟอร์มใดบ้าง

ยังไม่ เป็นต้นแบบเริ่มต้นที่สร้างสำหรับมือถือในแนวตั้ง ตอนนี้มีหนึ่งฉากและหนึ่งอาคาร และยังไม่มีบิลด์สาธารณะ หน้าร้าน หรือวันเปิดตัว

ใครเป็นผู้พัฒนา Stack Tower และติดตามได้อย่างไร

Stack Tower พัฒนาโดย WillowinWorlds สตูดิโอเกมมือถืออินดี้ (ดู เกมหลัก). ติดตาม WillowinWorlds ผ่านช่องโซเชียลที่ลิงก์ไว้ในหน้านี้ หรืออีเมล willowinworlds@gmail.com เพื่อขออัปเดตเกี่ยวกับ Stack Tower.
