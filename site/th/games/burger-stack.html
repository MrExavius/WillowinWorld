ต้นแบบเกมอาร์เคดเรียงซ้อน

Burger Stack

แตะเพื่อเรียงซ้อน เสิร์ฟออร์เดอร์

ปล่อยชั้นส่วนผสมลงบนเบอร์เกอร์ที่ใหญ่ขึ้น จัดให้เรียงกันและทำสูตรให้ตรงขณะสร้าง เก้าโหมดเปลี่ยนวิธีที่กองเคลื่อนและสิ่งที่คุณต้องไล่ตาม

เก้าโหมด ส่วนผสม 20 อย่าง และแคตตาล็อกสูตร 166 สูตร สร้างไว้ในโปรเจกต์ Unity ยังไม่มีบิลด์สาธารณะ

วิธีเล่น Burger Stack

  1. ขั้นตอนที่ 01เลือกแล้วปล่อย

    ชั้นเลื่อนไปเหนือกองและคุณแตะเพื่อปล่อย ในโหมดเรียงซ้อนคุณเลือกส่วนผสมถัดไปจากถาดได้

  2. ขั้นตอนที่ 02ลงจอดให้สะอาด

    ส่วนที่ยื่นออกจะถูกตัดทิ้ง ดังนั้นการปล่อยที่ไม่แม่นยำจะทำให้กองแคบลง การปล่อยที่ใกล้ศูนย์กลางนับเป็น Perfect และสร้างคอมโบ

  3. ขั้นตอนที่ 03ทำสูตรให้สำเร็จ

    ชั้นที่ตรงกับสูตรจะทำให้สูตรสำเร็จ ใน Order Rush แต่ละออร์เดอร์ที่เสร็จจะเพิ่มเวลา และส่วนผสมผิดจะเสียเวลา

โหมดครัวและกลไกการเรียงซ้อน

Stack Rush, Press Rush, Order Rush, Current Sort, Orbit Stack 3D, Stack 3D, Round 3D, Balance Tower 3D และ Slice & Fit 3D เลือกได้จากเมนูเลือกโหมด

ตัวจับเวลา Order Rush

ครัวที่เป็นภาพประกอบ

ฉากหลังครัวใต้น้ำและครัวท้องฟ้าเลื่อนเมื่อกองสูงขึ้น พร้อมถาดส่วนผสมและงานศิลป์ UI ที่เข้ากัน

ความคืบหน้าในเครื่อง

โปรไฟล์ที่บันทึกไว้ในเครื่องติดตามภารกิจรายวันและรายสัปดาห์ และส่วนผสมที่ปลดล็อกแล้ว

ทิศทาง

สถานะบิลด์และขั้นตอนถัดไปของ Burger Stack

ยังไม่มีวันเปิดตัว นี่คือเป้าหมายของโปรเจกต์ ไม่ใช่คำมั่นสัญญา

  • การวิเคราะห์ประสิทธิภาพและ QA บนโทรศัพท์ Android รุ่นสเปกต่ำก่อนการเปิดตัวใด ๆ
  • ธีมครัวเพิ่มเติมและการปลดล็อกของตกแต่งนอกเหนือจากชุดใต้น้ำและชุดท้องฟ้า (แนวคิดการออกแบบ ยังไม่ได้สร้าง)
  • คอลเลกชันสูตรและเป้าหมายการชำนาญ (แนวคิดการออกแบบ ยังไม่ได้สร้าง)
  • การบันทึกบนคลาวด์จะมาทีหลัง ตอนนี้ความคืบหน้าบันทึกในเครื่องเท่านั้น
รูปภาพ

แกลเลอรีงานศิลป์

ไฟล์งานศิลป์และอินเทอร์เฟซจากโปรเจกต์ Unity ไม่ใช่ภาพจับการเล่น

คำถามและคำตอบ

คำถามที่พบบ่อยเกี่ยวกับ Burger Stack

Burger Stack เป็นเกมประเภทใด

เกมอาร์เคดเรียงซ้อนแบบแตะธีมเบอร์เกอร์ คุณวางชั้นส่วนผสมลงบนกอง จัดให้ตรงกันและทำสูตรให้สำเร็จ มีเก้าโหมด รวมถึงโหมดรีบออเดอร์จับเวลาและรูปแบบ 3D แนวคิดแตะครั้งเดียวเดียวกันนี้ยังใช้ใน Sandwich Stack และ Stack Tower.

Burger Stack เปิดตัวแล้วหรือยัง และรองรับแพลตฟอร์มใดบ้าง

ยังไม่ Burger Stack เป็นต้นแบบที่ยังไม่มีบิลด์สาธารณะและยังไม่มีวันเปิดตัว แพลตฟอร์มที่ตั้งใจไว้คือ Android และ iOS

ใครเป็นผู้พัฒนา Burger Stack และติดตามได้อย่างไร

Burger Stack พัฒนาโดย WillowinWorlds สตูดิโอเกมมือถืออินดี้ (ดู เกมหลัก). ติดตาม WillowinWorlds ผ่านช่องโซเชียลที่ลิงก์ไว้ในหน้านี้ หรืออีเมล willowinworlds@gmail.com เพื่อขออัปเดตเกี่ยวกับ Burger Stack.
