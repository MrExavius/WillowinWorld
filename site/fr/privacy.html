Note de confidentialité WillowinWorld.

Ce site Web est un site public statique pour les jeux WillowinWorld et le matériel de presse. Il n'utilise pas de scripts d'analyse, de pixels publicitaires, d'intégrations tierces, de systèmes de compte ou de cookies de suivi.

E-mail de contact

Si vous envoyez un e-mail à WillowinWorld, votre message, votre adresse e-mail et tous les liens que vous fournissez sont utilisés uniquement pour répondre à votre demande.

Thème local

Le site peut stocker une petite préférence de thème local dans votre navigateur afin que le commutateur jour/nuit reste cohérent.

Brouillon de contact dans le même onglet

Pendant que vous remplissez le formulaire de contact de la page d'accueil, ses champs de nom, d'e-mail, de type de demande et de message sont conservés dans le stockage de session afin qu'un rechargement n'efface pas votre travail. Le brouillon reste sur votre appareil, peut être effacé dans le formulaire et est supprimé à la fin de la session de l'onglet du navigateur.

Aucun suivi tiers

Le site public évite les requêtes inutiles de tiers pour réduire la quantité de code extérieur chargé dans votre navigateur.
