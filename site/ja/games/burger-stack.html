プロトタイプアーケード積み上げゲーム

Burger Stack

タップして積む。注文を届けよう。

食材の層を育っていくバーガーに落とし、きれいに揃えて、組み立てながらレシピに合わせます。9つのモードでは、山の動き方と目指すものが変わります。

9つのモード、20種類の食材、166種のレシピ一覧がUnityプロジェクトに入っています。公開ビルドはまだありません。

Burger Stack のプレイ方法

  1. ステップ01選んで落とす

    層が積み上げた山の上をスライドし、タップして落とします。積み重ねモードでは、トレイから次の食材を選べます。

  2. ステップ02きれいに着地させる

    はみ出した部分は切り落とされるので、雑に落とすと山は細くなります。中央に近い落下はPerfectとして扱われ、コンボが増えます。

  3. ステップ03レシピを作る

    レシピに合う層を積むと、そのレシピが完成します。Order Rush では、注文を完成させるごとに時間が増え、間違った食材で時間が減ります。

特徴

キッチンモードと積み重ねの仕組み

9つのモード

Stack Rush、Press Rush、Order Rush、Current Sort、Orbit Stack 3D、Stack 3D、Round 3D、Balance Tower 3D、Slice & Fit 3D から、モード選択メニューで選べます。

エキスパート X/Z モディファイア

Stack Rush には、層を2つの軸に沿って動かす任意の Expert モディファイアがあります。

食材20種、レシピ166種

パティ、バンズ、トマト、ベーコン、ソース、フライドポテトなど。2～7種類の食材の組み合わせによるレシピ一覧があります。

Order Rush タイマー

シフトのタイマーは、注文を完了するたびに増え、間違った食材で減ります。

イラスト付きのキッチン

水中と空中のキッチンの背景は、山が高くなるにつれてスクロールし、食材トレイとUIアートもそれに合わせてあります。

端末内の進行状況

端末に保存されるプロフィールで、デイリーとウィークリーのチャレンジ、解放した食材を記録します。

Burger Stack よくある質問

Burger Stack はどんなゲームですか？

バーガーをテーマにした、タップで積むアーケードゲーム。食材の層を積み上げ、きれいに揃えてレシピを完成させます。制限時間つきの注文ラッシュや3Dバリエーションを含む9つのモードがあります。同じワンタップの発想が Sandwich Stack そして Stack Tower.

Burger Stack はもう公開されていますか？ 対応プラットフォームは？

まだです。Burger Stack はプロトタイプで、公開ビルドもリリース日もありません。対象プラットフォームは Android と iOS です。

Burger Stack を制作しているのは誰ですか？フォローするにはどうすればいいですか？
