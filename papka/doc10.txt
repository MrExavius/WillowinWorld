2. Главные проблемы
1. Отсутствие онбординга для интерактива: Пользователь не понимает, зачем кликать по экрану или искать скрытые буквы. Без подсказки магия остаётся «для гиков».
2. Тяжёлые GPUэффекты на мобильных: backdropfilter: blur(), dropshadow(), множественные radialgradient и colormix одновременно вызывают repaint на чипах уровня Snapdragon 6xx.
3. Заглушка формы контактов: Нет бэкенда, валидации, защиты от спама и подтверждения. При подключении SMTP/Edgeфункций сайт станет уязвим без Turnstile/reCAPTCHA и ratelimiting.
4. Отсутствие SEOразметки и метаданных для шаринга: Нет Open Graph, Twitter Cards, JSONLD. Ссылка на сайт в мессенджерах будет выглядеть «пусто».
5. Кастомные модалки вместо <dialog>: На мобильных браузерах кастомные диалоги ломают скроллблокировку и фокусменеджмент при использовании клавиатуры/скринридеров.
6. Нет прелоада критических ресурсов: Логотип, фон hero и шрифт Inter загружаются по запросу, что увеличивает LCP.

4. Подробный аудит по разделам
🎨 DESIGN / ART DIRECTION
Сайт использует «storybook» палитру: тёплые кремовые/золотые тона днём, глубокие синебирюзовые ночью. Композиция строится на асимметрии, стеклянных панелях и многослойных градиентах. Карточки игр уникализированы через cardaccent и кастомные @keyframes. Типографика Inter надёжна, но для игровой студии ей не хватает характера в заголовках. Рекомендация: добавить дисплейный шрифт (напр. Outfit или Clash Display) для H1/H2, оставив Inter для UI/копирайта. Усилить контраст в светлой теме для .muted текстов.
🧭 UX / USER EXPERIENCE
Структура логична: Hero → Games → Philosophy → Process → Careers → FAQ → Contact. Фильтры работают мгновенно. Модалки игр дают быстрый доступ к описанию без потери контекста. Единственное трение: секретные буквы (.secretglint) разбросаны по секциям, но пользователь не знает о них. Рекомендация: добавить subtle hint в HUD ("Explore. Click. Cast spells.") или всплывающую подсказку после 3го скролла. Контактный флоу должен иметь подтверждение отправки и link to Notion/Drive EPK.
💻 FRONTEND / CODE QUALITY
Код чистый, модульный, без глобальных переменных. Используются современные CSSфункции (colormix, :is(), aspectratio). IntersectionObserver корректно отключает ревиллы при lowMotion. Минусы: нет sizes у <img>, отсутствует loading="eager" для heroассетов, CSS не префиксирован и не минифицирован, нет :focusvisible на всех интерактивных элементах. Рекомендация: перейти на Vite/Esbuild для бандлинга, добавить sizes="(maxwidth: 640px) 100vw, (maxwidth: 920px) 50vw, 1180px", использовать contain: layout style paint на карточках.
⚡ PERFORMANCE / ЛАГИ / ОПТИМИЗАЦИЯ
Canvas рисует ~70 частиц, 2Dслои, звёзды. FPSтрекер автоматически снижает качество при <28 FPS. Это отлично. Но backdropfilter, mixblendmode, filter: dropshadow() и множественные radialgradient вызывают compositor repaint. На iPhone 12/Pixel 6 анимации будут стабильны, на бюджетных Android возможны просадки до 40–45 FPS при скролле через секции с играми. Рекомендация: заменить filter: dropshadow на boxshadow или ::before слои, вынести анимации в willchange: transform, opacity только на время анимации, добавить loading="lazy" и decoding="async" ко всем <img>, использовать fetchpriority="high" для heroлога.
🎬 MOTION DESIGN / INTERACTIVE EXPERIENCE
Сайт уже содержит: живой фон, кота, который следит за курсором, автодорисовку созвездия, portalэффект, частицы при клике, скрытые буквы. Всё работает на requestAnimationFrame и CSSанимациях. Риски: одновременный запуск 40+ @keyframes на секции .naturepreview и .ballstage может вызвать jank. Рекомендация: добавить prefersreducedmotion: reduce проверку не только в CSS, но и в JS для отключения canvasчастиц. Ввести pointermove throttle. Добавить haptic feedback (navigator.vibrate) на мобильных при сборе букв.
🏷️ BRANDING / GAME COMPANY IMAGE
Позиционирование чёткое: «cozy, tactile, mobilefirst, magical». Визуальный язык един: портал, семена, кот, два W. Сайт вызывает доверие у издателей благодаря структуре (process, pillars, progress). Не хватает: раздела Press/EPK, ссылок на Steam/Google Play/App Store, команды (даже анонимно), реальной дорожной карты. Рекомендация: добавить tone of voice в копирайт (меньше абстракций, больше фактов: «No ads. No paytowin. 100% offlinefirst.»), вставить виджет Discord/Telegram, сделать скачиваемый PDFpresskit с логотипами и гайдлайнами.
🔒 SECURITY / WEB SECURITY / ETHICAL HACKING AUDIT
Текущая защита сильная:
CSP запрещает inline, eval, внешние домены.
StrictTransportSecurity: maxage=31536000
XFrameOptions: DENY + COOP/CORP: sameorigin
PermissionsPolicy блокирует доступ к микрофону, камере, геолокации.
Нет innerHTML, document.write, fetch, WebSocket.
securitycheck.mjs автоматизирует аудит.
Остаточные риски:
Форма без бэкенда сейчас безопасна, но при подключении SMTP/Edgeфункций потребуется Turnstile, CSRFтокен, rate limiting (напр. Cloudflare Workers KV).
Отсутствует reporturi/reportto в CSP для мониторинга попыток инъекций.
Нет CrossOriginResourcePolicy: sameorigin для всех статических файлов (уже есть в headers, но убедитесь, что сервер отдаёт его для .webp, .css, .js).
Открытые assets/ директории. Рекомендация: закрыть доступ к /assets/Nature Seeds/ через Nginx location ~ ^/assets/.Seeds/.{ deny all; } и отдавать только оптимизированные превью через CDNrewrite.
🛡️ ЗАЩИТА ОТ КОПИРОВАНИЯ АССЕТОВ
✅ Реально полезно: водяные знаки на промоарте, отдача сжатых WebP/AVIF, отключение rightclick через CSS userselect: none; webkituserdrag: none;, скрытие исходников в /src/, hotlink protection через Nginx, DMCAконтакт в футере.
⚠️ Частично полезно: обфускация JS (снижает читаемость, но не останавливает devtools), отключение Ctrl+S (игнорируется через DevTools), защита от скриншотов (невозможно на уровне браузера).
❌ Бесполезная иллюзия: запрет выделения текста, скрипты «anticopy», шифрование JS на клиенте, DRM для изображений. Браузер уже получил данные; защита должна быть на сервере/CDN и юридической.
📱 MOBILEFIRST AUDIT
Hero на мобильных: текст clamp(3.05rem, 17vw, 4.4rem) читаем, кнопки minheight: 48px, grid вместо flex для CTA. Карточки становятся gridtemplatecolumns: 1fr, скролл удлиняется. Canvas автоматически снижает particleCount до 34 и DPR до 1.4. prefersreducedmotion работает. Проблемы: модалки не используют <dialog>, что ломает фокус и скроллблокировку на iOS Safari. backdropfilter на мобильных может вызывать артефакты. Рекомендация: заменить кастомные .modal на нативный <dialog>, добавить @supports (backdropfilter: blur()) фоллбэки, использовать touchaction: pany на canvas, внедрить IntersectionObserver для отключения canvas вне viewport на мобильных.

8. Финальная версия концепции сайта WillowinWorld

Hero (интерактивный, live day/night) → Games (фильтруемые карточки с liveпрогрессом) → Philosophy (6 принципов, таймлайн) → Devlog (3 последние записи) → Careers / Partners → FAQ → Contact (Turnstile + Edge) → Footer (EPK, соцсети, лицензии).
Визуальный стиль:
«Storybook 2.5D» с стекломорфизмом, мягкими тенями, кастомными CSSпеременными на каждую карточку. Две темы (Day/Night) синхронизированы с системными настройками, но с возможностью ручного переключения. Типографика: Clash Display (заголовки) + Inter (UI/копирайт). Цвета: fcfff2 ↔ 031735, акценты 71e7ff, ff4f73, ffe486.
Интерактив:
Canvasфон с котом, частицами, порталом.
Миниигра созвездия (клики/тапы по точкам).
Скрытые буквы по секциям с коллекцией и наградой.
Плавные IntersectionObserver ревиллы.
3Dнаклон карточек, hoverэффекты с colormix.
Все эффекты уважают prefersreducedmotion, saveData, lowend GPU.
Анимации:
Только transform, opacity, clippath. @keyframes ограничены 30–40 одновременно видимыми. Canvas FPSтрекер автоснижает качество. backdropfilter заменяется на фоллбэкградиенты при @supports.
Атмосфера:
Калиброванно «магическая», но не детская. Премиальная, спокойная, тактильная. Ощущение «живой мастерской», а не лендинга. Тон: уверенный, прозрачный, уважительный к времени игрока.

Vite build → минификация, бандлинг, asset hashing.
Nginx/CDN → CacheControl, HTTP/2, Brotli, strictcsp.
Edge Functions → форма, ratelimiting, Turnstile.
JSONLD → Organization, VideoGame, FAQPage.
CI/CD → securitycheck.mjs, Lighthouse CI, axe, Playwright e2e.
Безопасность:
Строгий CSP с reporturi, отсутствие внешних скриптов, PermissionsPolicy, COOP/CORP, HSTS, защита формы от спама/DoS, водяные знаки на ассетах, закрытые директории в Nginx, DMCAконтакт, регулярный аудит зависимостей.

Touchинтерфейс лишён визуальной обратной связи Эффекты при наведении (shine, glow) полностью отключены на тачустройствах без альтернативы. 
💻 Frontend / Архитектура
Наблюдение  Краткое описание 
Хардкод координат секретов sectionSecretSpots использует процентные координаты любое изменение вёрстки ломает механику без ошибки в консоли. 
Каскад CSSпеременных с colormix() Сложные вложенные вычисления (var(cardaccent, var(cyan))) создают трудноотлаживаемые баги при смене темы.

Нет обработки ошибок в canvasрендеринге Любая ошибка в ctx.arc() или загрузке изображения останавливает анимационный цикл без уведомления пользователя. 
Дублирование keyframesанимаций Похожие анимации (natureWaterCycle, natureBloomCycle) определены отдельно сложно менять тайминги глобально. 
⚡ Производительность
Наблюдение  Краткое описание 
Backdropfilter + множественные слои 3+ элемента с backdropfilter: blur() создают отдельный render pass на мобильных GPU просадки до 35–40 FPS. 
filter: dropshadow() на анимируемых элементах Тень пересчитывается каждый кадр при трансформации главная причина jank на Snapdragon 6xx/7xx. 
Canvas не использует батчинг отрисовки 70 частиц = 70 отдельных ctx.arc() вызовов/кадр. Path2D или offscreen batching могли бы снизить нагрузку на 30–40%. 
Шрифты без fontdisplay и preload Inter загружается без стратегии возможен FOIT/FOUT и сдвиг макета (CLS). 
RAFцикл не уступает браузеру Непрерывный requestAnimationFrame может голодать другие задачи (layout, input), особенно на слабых устройствах.

💡 Бонус: Быстрые победы (можно сделать за 1 день)
1. Добавить og:image сразу улучшит отображение ссылок в соцсетях.
2. Создать /press страницу даже простая текстовая версия уже работает.
3. Зарегистрировать сайт в Google Search Console ускорит индексацию.
4. Добавить якорные ссылки с ключевыми словами:
html
<a href="games">cozy mobile puzzle games</a>
<a href="studio">indie game studio</a>

5. Указать платформы в описаниях игр: «Coming soon to iOS and Android» это частый поисковый запрос.
> Финальный совет: Не пытайтесь оптимизировать всё сразу. Начните с технического фундамента(JSONLD, OGтеги, sitemap), затем добавьте контентную глубину(отдельные страницы игр, devlog), и только потом фокусируйтесь на внешнем продвижении. Поисковые системы ценят последовательность и качество, а не спешку.
Нужна помощь с реализацией конкретного пункта (например, генерация JSONLD для всех игр или настройка Search Console)? Готов помочь с кодом или пошаговой инструкцией.
