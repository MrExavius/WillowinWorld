9. Углублённый аудит конкретные действия
9.1 Canvas Performance конкретные цифры
Текущее состояние:
70 частиц (desktop) + 34 звёзд (dark) + 48 звёзд (light)
Кошка рисуется каждый кадр (bezier + cat drawing)
Созвездия, порталы, следы, всплески всё каждый кадр
При 60fps это ~3600 рисований в секунду на desktop
На мобильных:
particleCount = 34
Но звёзд 52 (dark) / 30 (light)
Кошка масштабируется больше пикселей
Итого ~15002000 рисований/сек
Решение:
javascript
// В scripts.js добавить проверку производительности
function checkPerformance() {
 const fps = state.fpsScore;
 if (fps < 30 && !state.lowMotion) {
 state.lowMotion = true;
 state.particleCount = 18;
 state.quality = "Low";
 body.classList.add("lowmotion");
 seedScene();
 showToast("Switching to lowperformance mode");
 }
}
// Вызывать каждые 5 секунд
setInterval(checkPerformance, 5000);
Также добавить в resize():
javascript
if (state.width < 700) {
 state.particleCount = 20; // вместо 34
}

9.7 Security полный чеклист
Текущее состояние:
CSP есть
HSTS есть
XFrameOptions: DENY
ReferrerPolicy: noreferrer
Угрозы:
1. Контактная форма XSS через input
Решение: санитизация на сервере, ContentSecurityPolicy
2. Нет CSRF защиты
Решение: CSRF токен или SameSite cookies
3. Нет rate limiting
Решение: nginx rate limiting или middleware
4. Нет защиты от ботов
Решение: reCAPTCHA v3 или hCaptcha
5. localStorage для темы может быть атаковано XSS
Решение: если CSP строгий, это безопасно
Nginx дополнительно:
nginx
Rate limiting
limit_req_zone $binary_remote_addr zone=contact:10m rate=1r/m;
limit_req zone=contact burst=3 nodelay;
Защита от скриптинга
add_header XXSSProtection "1; mode=block";
add_header XContentTypeOptions "nosniff";

Не использовать: Оставлять форму пустой, не фиксировать утечку rafId, не ограничивать DPR.

FPS на реальном мобильном устройстве (не эмуляторе)

Модалки при быстром закрытии вкладки
Секретные буквы на экранах 320360px
Canvas при DPR 3 (MacBook Pro 16", некоторые Android)
Где остаётся неопределённость:
Производительность на устройствах с 12GB RAM и слабым GPU нужно тестирование

Как Google Fonts поведёт себя с CSP fontsrc 'none' фоллбэк на системные шрифты

10. Честный вывод
Что даст результат быстро:
Title + description + OGтеги → через 12 недели
Сжатие изображений → Core Web Vitals → через 1 неделю
Structured data → через 24 недели
Ключевые слова в текстах → через 24 недели
Что даст результат медленно:
Link building → через 13 месяца
Content marketing → через 12 месяца
Репутация в сообществе → через 36 месяцев
Главный риск: если сайт будет медленным и без контента SEO не поможет. Сначала техническая база, потом контент, потом ссылки.
Что обязательно сделать:
1. Title + description с ключевыми словами
2. Structured data
3. Сжать изображения
4. Добавить width/height
5. Создать sitemap + robots.txt
Что можно оставить на потом:
Link building (не критично для старта)
YouTubeканал (если нет ресурсов)
Analytics (если нет бюджета на инструменты)
Итог: если сделать пункты 15, сайт будет готов к индексации и покажет результаты в поиске через 24 недели. Для более высокой позиции нужна стратегия link building и content marketing на 36 месяцев.
