PERFORMANCE AUDIT
Самые опасные места
1. Canvas + DOM animation одновременно
Очень дорого.
Особенно:
mobile GPU;
Safari iOS.
2. Огромное количество WebP
Даже WebP:
если layered simultaneously
memory pressure высокий.
3. Blur и opacity
Если используются:
backdropfilter;
heavy shadow blur;
glowing effects
будет GPU thrashing.
Что делать
Обязательно
intersectionbased animation pause;
pause offscreen scenes;
adaptive particle budgets;
sprite atlas;
reduce layered alpha;
compress textures aggressively.
Production targets
Mobile:
55–60 FPS
< 180 MB memory
< 2.5 sec LCP
< 0.1 CLS
