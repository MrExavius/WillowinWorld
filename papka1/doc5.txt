3.1. Контактная форма — это mailto обёртка

Почему критично издателиинвесторы заходят с корпоративных машин, где mailto либо не настроен, либо открывает Outlook вместо Gmail, либо вообще игнорируется. 30–50% реальных лидов теряется. 3.4. URLencoded пробелы в путях ассетов (Ball%20is%20God, Nature%20Seeds, Candy%20Shop, Paint%20Blasters)
Это бомба замедленного действия
На некоторых CDNпрокси URLdecoded vs encoded версии кешируются как разные ключи → 2× cache miss.
При портировании на CICD некоторые билдсистемы (особенно Windows) ломаются на пробелах.
При сканировании LighthouseSearch Console пути с %20 иногда не индексируются.
Регулярный source diff даёт мусор.
Фикс переименуйте папки → assetsballisgod, assetsnatureseed, assetscandyshop, assetspaintblasters. Это 30 минут работы и большоеснижение хрупкости.

🟠 СРЕДНЕВАЖНО
3.6. CacheControl nocache на HTML — спорно
apache
ExpiresByType html "access plus 0 seconds"
Для контентного сайта это нормально, но HTTPS HSTS + immutable assets + всегдаnocache HTML означает, что TTFB при возврате юзера всегда новый. Лучше CacheControl public, maxage=0, mustrevalidate + ETag — браузер сделает conditional request и получит 304, без загрузки тела.
3.7. scriptsrc self без strictdynamic
Если когданибудь добавите динамические скрипты (например, аналитику), CSP заблокирует. Современная best practice 2026(web.dev  Google CSP team) scriptsrc self strictdynamic nonce{random}. Сейчас вы используете sha256... для JSONLD — это валидно, но при любом изменении JSONLD надо пересчитать хэш и обновить во ВСЕХ местах(_headers, .htaccess, nginx.conf, <meta>). Buildскрипт это валидирует, но при git pull легко поймать broken CSP.
3.8. framesrc none + childsrc none блокирует YouTubeVimeo трейлеры
Если планируете показать gameplay trailer на index — придётся вырезать видео или сильно ослабить CSP. Альтернативы liteyoutubeembed selfhosted thumbnail + <a href> к YouTube, или <video src="owncdntrailer.mp4"> (mediasrc self — но сейчас стоит none).
3.9. Localstorage без trycatch в setTheme
js
localStorage.setItem("willowtheme", theme);
Я нашёл trycatch у чтения, но setTheme пишет внутри tryобёртки только частично — на Safari в private mode setItem может бросать QuotaExceededError. Сейчас это может вызвать unhandled error → разрыв renderloop. Проверьте все .setItem и оберните в try.
3.10. preferscolorscheme overrides without manual toggle persistence
js
if (!savedTheme && typeof colorSchemeQuery.addEventListener === "function") {
colorSchemeQuery.addEventListener("change", event => setTheme(event.matches "dark" "light", false));
}
Это хорошо, но FOUC при первом рендеревозможен theme устанавливается послепарсинга HTML, body уже отрендерен с дефолтным datatheme="light". Используйте inlinescript с inline CSP hashв <head> для блокирующей установки темы до paint(Next.js так делает themescript). Сейчас это нарушает CSP, потому что inline scripts запрещены кроме JSONLD. Workaround добавить второй sha256hash в CSP, чтобы разрешить минискрипт темы.
3.11. Logo swap через theme === "dark" "logo.webp" "logoday.webp" → CLS
При смене темы <img src> меняется → браузер делает новый запрос → пустота → загрузка. Решение prefetch обоих логотипов + CSS <picture> с preferscolorschemeили использовать единый SVG logo с CSSпеременными (currentColorCSS vars в SVG).
3.12. <canvas> ariahidden="true" — но интерактивен
magicCanvas принимает clicktouch (создаёт clickBursts). Скринридер не объявит об этом, а keyboardonly users не могут активировать секреты(secretRewards). Это нарушение WCAG 2.1.4.7 «Audio Control» по духу. Добавьте либо альтернативный keyboardtrigger ( → открывает modal со списком eastereggs), либо явное предупреждение в Skiplink меню.
3.13. Размер styles.css ~10 000+ строк
Один файл, всё в root и тематических классах через CSSкаскад. Нет cascade layers (@layer), нет critical CSS extraction. LCPстрадает потому, что блокирующий CSS грузится целиком до first paint. Рекомендую
Разбить на base.css (vars, reset, layout) + pages.css + components.css
На каждой gamepage подключать только нужный + global, через <link rel="preload" as="style">
Inline критический CSS (~10 KB) для index hero
Использовать @layer base, components, utilities, themes чтобы избежать specificityвойн
3.14. Все .html страницы дублируют почти 100% CSP <meta> content
CSP <meta> дублируетHTTPheaders. Это избыточнои потенциально опасно если когдато расходятся (например, _headers обновили, а HTML забыли), браузер применит strictestcombined CSP. На gamepages scriptsrc self без sha256 — то есть JSONLD inline на этих страницах сломался бы, если бы он там был. Проверьте, что нет рассинхронизациимежду <meta httpequiv> и _headers.
3.15. <a class="btn btnsmall btnghost errorgameheader" href="404.html">404<a> в шапке
Это очень странноеUXрешение — кнопка «404» в основной навигации. На press kit или для издателя это выглядит как баг. Это eastereggминиигра «Catch the Lost Stars», но пользователь без подсказки не понимает. Уберите из основной навы → пусть появляется только при настоящем 404. Или сделайте «Minigame ★» с tooltip.
🟢 Дополнительные улучшения (после релиза)
3.16. Отсутствуют hreflang  locale alternatives
Сайт lang="en". Если планируете RUZHES рынки (а для cosy мобильных игр это главныерынки) — добавьте <link rel="alternate" hreflang="ru" href="..."> заранее.
3.17. Нет <link rel="preconnect"> к будущим источникам
Сейчас всё self, поэтому неактуально. Но как только подключите backend API — preconnect обязателен.
3.18. Нет ReportingEndpoints  ReportTo для CSP violations
Раз уж у вас такой строгий CSP — подключите CSP reporting. Узнаете, какие реальные нарушения видят пользователи в production. Endpoint reportto → собственный Worker → лог в KV.
3.19. Service Worker отсутствует
manifest.webmanifest есть, display standalone, но нет SW→ нет offline, нет addtohomescreen с кешом. Для cozymobilestudio это упущенный wowэффект (PWAinstallable studio site).
3.20. Нет <link rel="prefetch"> для innerpage navigation
При переходе index → gamesnatureseed.html грузится весь styles.css заново(хоть и из кеша). Используйте <link rel="prefetch" href="gamesnatureseed.html"> для топ3 игр.
3.21. Изображения 12 preload, 104 lazy
Преложений на ОДНОЙ странице 12— это слишком многодля fetchpriority="high". Браузер distributes priority, и фактически ничего не приоритизируется. Оставьте 2–3 preload максимумна самые важные ассеты hero.
3.22. sitemap.xml не содержит <imagecaption>
Для gamepages добавьте <imageimage> блок с <imagetitle>, <imagecaption>, <imagelicense> — это улучшает Google Image Search ранкинг для игровых иконок.
3.23. Все progressbars <div role="group" arialabel="... 99 percent"> без <progress>
Семантически правильный элемент — <progress max="100" value="99">. Скринридеры объявят его правильно, а не как «99 percent ».
3.24. Modal ariamodal="true" но без focustrap в чистом виде
Я вижу trapModalFocus(event) в keydown listener — хорошо. Но если CSS Layout Engine изменит видимый порядок (например, flex rowreverse), focus order сломается. Используйте inert атрибут на <main> когда modal открыт — это новый стандарт.
3.25. Игровые карточки используют псевдо3D через множество абсолютнопозиционированных <img> + <span>
Тяжёлый DOM для card. На странице index.html в gamesgrid 4 card × ~40 layered DOMузлов = ~160 элементов только в визуальной части. На lowend Android это создаёт jank при скролле. Альтернатива — <canvas> для preview, или SVGкомпозицияв один файл с встроенными <animate> (чтото вроде Lottie без JS).
